2. 연결 탭
Inst > 노래기록 연결: Inst 주소 입력 또는 검색 → 제목에 맞는 날짜별 기록/원곡 타임스탬프 선택.
노래기록 + inst 연결: 곡명·날짜로 기록 선택 → Inst 연결.
이력없음 + inst 연결: 미가창 전용 178건에서 선택 → Inst 연결.
SRT + inst 연결: SRT 텍스트 붙여넣기 → 'SRT 분석해서 배치' → Inst 연결.
검색 결과의 섬네일은 새 탭 확인, 제목은 Inst 연결입니다.

3. 시간 조절
전체 오프셋: 초 단위 입력 후 적용. +1은 1초 늦추기, -1은 1초 앞당기기입니다. 값은 전체 보정량입니다.
개별 cue: 일시정지 → 큐 블록/우측 행 선택 → 시작·종료 시각 입력 또는 '현재 시각으로'.
드래그: 전환점 타임스탬프를 좌우로 끌어 조정합니다. 공통 전환점은 앞 cue 끝과 다음 cue 시작이 함께 움직입니다.
타임라인 배경 드래그는 재생 위치를 탐색합니다.
2초 이상 가사 공백과 빈 cue는 자막 없는 구간으로 유지합니다.
연결한 Inst를 재생하며 최종 타이밍을 확인하세요.

4. 가사 편집
우측 리스트에서 원문을 수정하고 '한'으로 번역을 펼칩니다.
Split: 나눌 시각에 멈추고 누릅니다. 가사에도 분할 위치를 지정하려면 글자 사이에 커서를 놓고 Split 버튼을 누르세요.
New: 빈 구간에 cue 추가. Delete: 선택 cue 삭제. Undo: 직전 편집 취소.

5. 단축키
Space 재생/일시정지 · ←/→ 5초 이동 · S Split · N New · Z Undo · Delete 삭제
전환점에 초점이 있으면 ←/→는 0.1초 조정입니다.
입력란·YouTube 내부에서는 페이지 버튼을 사용하세요.

6. 저장
우측 '원문 SRT 다운로드' 또는 '원문+한국어 SRT 다운로드'로 현재 편집본을 저장합니다.
상단 '포실 클립스 전체 SRT'에서 등록 자료 전체를 받습니다.
로컬 히스토리: 같은 브라우저·사이트의 최근 연결 10개 자동 저장 → 매칭 이름 선택 → 복원.
