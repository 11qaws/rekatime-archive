REKATIME PORTING 사용설명서
기준: 2026-10-18 · 배포 버전 1.1.124
페이지: https://rekatime.pages.dev/rekatime-porting.html

1. 이 묶음에 들어 있는 자료
총 996건의 SRT 자료입니다. 같은 노래의 날짜별 기록과 원본 참조는 별도 자료이므로, 고유 노래 996곡이라는 의미는 아닙니다.
곡별 커버리지: 558곡. 노래 기록 334곡 + 원본 참조 438곡 - 공통 214곡입니다.
동일 노래책 ID를 우선 묶고, ID가 없는 4곡은 곡명+원곡자로 묶었습니다. 노래책에서 별도 ID로 관리하는 판본은 별도 곡으로 집계합니다.
곡별_커버리지.csv는 곡 단위 목록과 자료ID/SRT 경로를 제공합니다.
- 노래 기록 기반: 558건. 날짜별 노래 기록의 타임스탬프입니다.
- 원본 타임스탬프 기반: 438건. 원본 동기화 가사(LRC) 398건, 원본 자막·가사 대조 40건입니다.
- 미가창 전용 목록: 178건. 위 원본 자료에 포함되는 하위 목록이며 별도로 중복 수록하지 않습니다.

SRT/노래기록/에는 기존 노래 기록 자료가, SRT/원본타임스탬프/에는 별도 원본 참조 자료가 있습니다.
곡별_상태.csv는 자료 단위(날짜별 기록·원본 참조별) 표 계산 프로그램용, 곡별_상태.txt는 일반 텍스트 열람용입니다. 자료ID와 SRT 경로로 각 파일을 찾을 수 있습니다.
시각 오류로 제외한 노래 기록 3건과 공개 보류 자료는 포함하지 않습니다. 브라우저에서 개인적으로 수정한 편집본은 이 묶음에 포함되지 않습니다.

2. 원문 ZIP과 원문+한국어 ZIP
두 ZIP은 동일한 996건을 담습니다.
- 원문 ZIP: 원문 가사만 수록합니다.
- 원문+한국어 ZIP: 기존 번역이 있는 행에만 한국어를 함께 수록합니다.
- 번역이 없는 행은 원문만 남습니다. 새 번역을 만들거나 원문을 번역으로 복제하지 않습니다.
- 한국어 원곡은 한국어를 두 번 표시하지 않습니다.
현재 자료의 한국어 상태: 전체 번역 491건 / 일부 번역 29건 / 한국어 원곡 38건 / 별도 번역 없음 438건.
'전체 번역'은 비어 있지 않은 가사 cue마다 별도 번역이 있다는 뜻이며 번역 품질 승인이라는 뜻이 아닙니다.
상태표의 번역 여부는 원본 자료가 가진 정보입니다. 원문 전용 ZIP에는 번역이 출력되지 않습니다.

3. 연결 순서
① Inst 직접 연결 또는 Youtube 검색
YouTube Inst 주소를 붙여넣거나 곡명을 검색합니다. Inst·Off Vocal·MR이 우선 표시됩니다.
검색 결과의 섬네일은 YouTube 새 탭 확인용이고, 제목은 Inst 연결 버튼입니다.
② 원본 타임스탬프 또는 노래 기록 매칭
매칭 목록에서 날짜별 노래 기록 또는 '원곡 타임스탬프'를 선택합니다.
예: 호시아이는 날짜별 노래 기록 8건과 원본 타임스탬프 1건 중 선택할 수 있습니다.
Inst와 자막이 연결되면 설정 영역이 접힙니다. 설정을 다시 펼쳐 대상을 바꿀 수 있습니다.
탭별 이용 방법
[1] Inst > 노래기록 연결
Inst부터 정할 때 사용합니다. 주소 연결 또는 YouTube 검색 → 영상 제목 확인 → 날짜별 노래 기록 또는 원곡 타임스탬프 선택 순서입니다.
영상 제목이 자동으로 표시되지 않으면 제목을 입력해 매칭 후보를 찾습니다. 날짜별 노래 기록은 그날의 시각이고, 원곡 타임스탬프는 별도의 원본 시각입니다.

[2] 노래기록 + inst 연결
수정할 노래 기록부터 정할 때 사용합니다. 곡 찾기에서 곡명/날짜 검색 → 자막 연결에서 날짜별 노래 기록 또는 원곡 타임스탬프 선택 → Inst 연결 순서입니다.
목록이 많을 때 먼저 원하는 기록을 찾는 방식입니다.

[3] 이력없음 + inst 연결
노래 기록이 없지만 원곡 시각이 확보된 자료를 찾을 때 사용합니다. 미가창 전용 목록에서 곡 선택 → Inst 연결 순서입니다.
이 목록 178건은 전체 원본 참조 438건에 포함됩니다. 노래와 함께 타이밍 검증되지 않았다는 주의 표시를 확인하세요.

[4] SRT + inst 연결
직접 가진 SRT를 수정할 때 사용합니다. 번호·시작/종료 시각·가사를 포함한 SRT 텍스트를 붙여넣고 'SRT 분석해서 배치'를 누른 뒤 Inst를 연결합니다.
SRT/JSON 파일 열기 대신 텍스트를 붙여넣습니다. 이 작업은 현재 편집 cue를 붙여넣은 내용으로 교체합니다.

네 탭 모두 Inst와 자막이 해당 연결 방식에서 지정되어야 편집할 수 있습니다. 다른 탭으로 바꾸면 그 탭에서 필요한 입력을 지정하세요.


4. 전체 타이밍 조절
전체가 일정하게 어긋나면 '전체 오프셋'에 초 단위 값을 입력하고 적용합니다.
+1.0은 1초 늦추기, -1.0은 1초 앞당기기입니다.
입력값은 전체 보정값입니다. 같은 값을 반복 적용해도 추가로 이동하지 않습니다.

5. 개별 cue 타이밍 조절
일시정지하고 타임라인 큐 블록 또는 오른쪽 큐 행을 선택합니다. 선택 표시와 현재 재생 중인 cue 강조는 서로 다릅니다.
- 시작·종료 시각을 초 단위 숫자로 입력합니다.
- 타임라인 전환점의 작은 타임스탬프를 누른 채 좌우로 드래그합니다. 왼쪽은 시각 당기기, 오른쪽은 시각 늦추기입니다. 일시정지 상태에서만 동작합니다.
- 맞닿은 두 cue의 공통 전환점은 하나만 표시하며 드래그하면 앞 cue의 끝과 다음 cue의 시작이 함께 움직입니다. 공백으로 떨어진 시작/끝은 각각 조정합니다.
- 타임라인 배경을 드래그하면 영상의 재생 위치를 탐색합니다. cue 시각을 바꾸는 전환점 드래그와 구별하세요. 경계의 시작/끝을 역전시키는 수정은 적용되지 않습니다.
- 원하는 순간에 멈춘 뒤 시작 또는 종료의 '현재 시각으로'를 누릅니다.
가사 사이 공백이 2초 미만이면 다음 가사 시작까지 연결하며, 2초 이상이거나 명시된 빈 cue는 자막 없는 구간으로 유지합니다.

6. 가사 편집·분할·추가·삭제
오른쪽 큐 리스트에서 원문을 바로 수정합니다. '한' 버튼으로 한국어 번역을 펼치거나 접습니다.
분할할 글자 위치에 커서를 놓고, 영상도 분할 시각에 멈춘 뒤 Split 버튼을 누릅니다.
글자 위치를 지정하지 않은 원문 또는 번역은 분할된 두 cue에 그대로 유지됩니다. 원문과 번역의 커서는 각각 지정할 수 있습니다.
New는 빈 구간에 새 cue를 추가합니다. Delete는 선택 cue를 삭제하며 Undo로 직전 편집을 취소합니다.

7. 단축키
Space: 재생·일시정지 / ←·→: 5초 뒤로·앞으로
S: Split / N: New / Z: Undo / Delete: 선택 cue 삭제
타임라인 전환점에 초점이 있으면 화살표는 0.1초 경계 조정으로 동작합니다. 5초 영상 이동을 하려면 타임라인 배경/큐 블록에 초점을 두거나 -5초/+5초 버튼을 누르세요.
New 직후에는 Z로 새 cue 추가를 취소할 수 있습니다. 새 cue에 가사를 입력했다면 Undo 한 번은 가사 입력, 다음 Undo는 cue 추가를 취소합니다.
Split은 영상의 현재 재생 시각을 기준으로 나눕니다. 선택한 다른 cue가 아니라 현재 시간침이 들어 있는 cue를 분할합니다.
가사·숫자 입력란과 YouTube 내부에서는 페이지 버튼을 사용하세요.

8. 다운로드와 복원
오른쪽 '원문 SRT 다운로드' 또는 '원문+한국어 SRT 다운로드'는 현재 편집본을 저장합니다.
상단 '포실 클립스 전체 SRT'는 이 등록 자료 모음을 받는 기능입니다.
최근 연결 10개는 같은 브라우저·같은 사이트 주소의 로컬 히스토리에 자동 저장됩니다.
매칭 이름을 선택하고 복원을 누르면 Inst·가사·cue 시각·전체 오프셋을 복원합니다.
로컬 주소와 배포 주소의 브라우저 저장소는 서로 다릅니다.

9. 타이밍 상태 읽는 법
노래 기록 시각은 해당 노래 기록 기준이며 다른 Inst와의 일치를 보장하지 않습니다.
원본 LRC 시각은 실제 원본 동기화 가사 자료의 시각이며, 원본 자막·가사 대조 시각은 원본 자막 시각과 가사를 대조한 초안입니다.
원본 자료는 '(주의) 노래와 함께 타이밍 검증되지 않았음' 상태를 유지합니다.
모든 포함 자료는 편집용 초안이며, 이 묶음이 제작·타이밍 검수 승인을 새로 부여하지 않습니다.
곡별_상태 파일에서 각 자료의 출처·번역·cue 수를 확인하고, 연결한 Inst를 직접 재생하며 시간을 맞춘 뒤 최종 SRT를 저장하세요.
